# The Impossible Room — GDD v1.0 Handoff

Contents:
- `GDD.md`: full creative, narrative, gameplay, visual and acceptance specification.
- `CODEX_BRIEF.md`: staged implementation instructions and quality gates.

**Recommended use:** Give Codex both documents. Have it demonstrate the P0 visual proof of concept before scaling to the complete case. The realistic graphic-novel quality target is a required visual acceptance gate, not a promise that generic procedural art can satisfy it.

**Important creative choice:** The first case deliberately subverts the expectation of an ingenious locked-room murder. It is an apparently impossible death accompanied by unrelated environmental phenomena. This is consistent with the franchise premise that not every mystery is a crime. If the first playtest finds this unsatisfying, revise the narrative rather than disguising weak evidence.
